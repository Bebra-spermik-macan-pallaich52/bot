## Ограничения и блокеры

- Первый внешний запрос Bybit из основного процесса облака не проходил через прокси
  (CONNECT 403). В Docker WebSocket работает, но HTTPS REST Bybit возвращает
  HTTP 403 и текст `The Amazon CloudFront distribution is configured to block
  access from your country`. Это подтверждённый региональный запрет REST в данной
  среде. Он не исправляется повторными запросами. Обход не реализован.
- В draft добавлены `api.bybit.com`, `stream.bybit.com`. Также сохранены install_script и start_skill. Сохранение draft не означает
  применения/публикации. Runtime status не подтверждает enforced актуальную
  сетевую политику. Наблюдения конкретных запросов приведены отдельно выше.
- Полнота реальной истории, восстановление реальных длительных пропусков через
  публичный REST и численная статистика на рыночной выборке **не проверены**.
- Система не объявляется готовой к полноценному автономному сбору до успешного
  REST-запуска в поддерживаемом регионе. Длительный soak-test 24/7 не проводился.
- Внешние оповещения, off-host backup, ротация host cron-логов и автоматический
  контроль диска нужно подключить на сервере. Проверки healthcheck предусмотрены,
  но статус unhealthy не вызывает автоматического restart Docker.
- Выборка синтетических тестов не доказывает наличие прогнозной закономерности.
  Прибыльность не установлена. Bootstrap CI описательный, без коррекции
  множественных попыток; независимый фиксированный будущий holdout ещё требуется.
- Базовая версия отправлена в GitHub коммитом `95c4672`. Публикация облачной
  конфигурации и восстановление окружения в новой задаче не проверены.
